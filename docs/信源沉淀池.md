# 信源沉淀池

跨主题的可复用抓取渠道目录。热点主题在启用 / 保存配置时，按问卷意图推断场景标签，与池内条目标签求交后克隆到主题「来源管理」（另固定配 SearXNG）。

## 维护入口（以仓库脚本为准）

| 文件 | 作用 |
|------|------|
| [`scripts/bootstrap/source-channel-catalog.json`](../scripts/bootstrap/source-channel-catalog.json) | **权威种子**：渠道列表、标签、`sortOrder` |
| [`scripts/bootstrap/Initialize-ChengwenfangSeed.ps1`](../scripts/bootstrap/Initialize-ChengwenfangSeed.ps1) / `.sh` | 启动 `bootstrap-seed`：Flyway 建表后导入本 JSON（缺则插；`-Force` 覆盖元数据） |
| `source_channel_catalog` 表 | 运行时真相；由 Flyway `V16` 建表，`V16`/`V17` 含基线 INSERT |
| `SourceChannelCatalogTags` / `SourceChannelCatalogCodes` | Java 闭集常量，须与 JSON 的 `tags` / `code` 对齐 |

新增或改 URL：先改 JSON → 跑初始化脚本（已有行需 `-Force`）→ 同步改 Codes 常量与（可选）Flyway 增量。不要只改库内一行而不改仓库种子。

## 场景标签（闭集）

当前仅：

| 标签 | 含义 | 主题问卷启发式关键词（节选） |
|------|------|------------------------------|
| `ai` | AI / 大模型 | ai、llm、gpt、claude、人工智能、大模型… |
| `web3` | Web3 / 加密 | web3、crypto、区块链、比特币… |

推断见 `HotNewsThemeCatalogTagInferrer`；匹配与配额见 `HotNewsChannelCatalogMatcher`、`HotNewsChannelAutoWireLimits.MAX_CATALOG_MATCHES`（默认最多克隆 8 条，不含 SearXNG）。

## 与主题来源的关系

- 沉淀池：`source_channel_catalog`（无 `theme_id`）
- 主题渠道：`source_channels`（有 `theme_id`）；克隆后可在来源管理里开关/删除
- 已创建主题不会自动长出新池条目；需再保存主题配置触发配源同步，或新建主题

## 初始化命令

```powershell
# Windows；MySQL 已就绪
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap\Initialize-ChengwenfangSeed.ps1
# 用 JSON 覆盖已有沉淀池行时：
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap\Initialize-ChengwenfangSeed.ps1 -Force
```

```bash
./scripts/bootstrap/Initialize-ChengwenfangSeed.sh
./scripts/bootstrap/Initialize-ChengwenfangSeed.sh --force
```
