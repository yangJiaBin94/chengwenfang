## 2. 产品目标

在课程体系教学模式内，用户通过多步提问 + 选项选择创建结构完整的主题，并支持修改、停用、删除（有约束）。

**完整主题（结构完整，非全文已写完）** 必备：

1. 主题元数据（名称、编码、受众、目标、难度、风格约束、状态）
2. 课程系列（≥1，含名称、排序、定位）
3. 课程课次（每系列 ≥1，含课号、标题、摘要）
4. 课程路线（系列 `sort_order` + 课内 `lesson_no` 为权威顺序；可附路线说明）

**本期不做：** 批量自动写完全部原稿/公众号；模式管理；主题级 Skill/工作流绑定；与 `publishing_themes` 混淆。

**默认策略：** 问卷 → AI 生成课表草案 → 用户确认编辑 → 落库课壳；正文仍按课走现有 `course-content-generation`。

---

## 3. 状态机

```text
draft                向导未完成（仅有 briefing）
ready_for_review     已有 curriculum 草案，未 commit
enabled              已确认落库，可进入路线与单课生成
disabled             停用，默认列表不可见
```

转移：

- 创建草稿 → `draft`
- 保存问卷至完整 → 仍可 `draft`
- 生成课表成功 → `ready_for_review`
- commit 成功 → `enabled`
- 停用 / 启用 → `disabled` ↔ `enabled`（仅已 commit）
- 删除：仅 `draft` / `ready_for_review`，或 `enabled`/`disabled` 且无有效正文且无进行中 job；`created_via=seed` 禁止删除

## 4. 问卷字段合约（briefing_json）

`schema_version`: `1`

  "step": 6,
  "naming": {

    "description": "一句话卖点",

  "goals": {

    "success_criteria": "project|understand|publish"
  },
  "scope": {

    "difficulty_curve": "gentle|easy_to_hard|project_spiral"
  },
  "structure": {
    "series_count_pref": "3_5|5_8|custom",
    "series_count_custom": null,
    "lessons_per_series_pref": "3_5|5_8|custom",

## 5. 课表草案合约（curriculum_draft_json）

```json
{
  "schema_version": 1,
  "route_narrative": "为什么按这个顺序学",
  "series": [
    {
      "temp_id": "s1",
      "name": "系列名",
      "sort_order": 1,
      "positioning": "一句话定位",
      "lessons": [
        {
          "lesson_no": 1,
          "title": "课标题",
          "summary": "摘要",
          "learning_outcomes": ["可选"]
        }
      ]
    }
  ]
}
```

上限：系列 ≤ 20；单系列课 ≤ 30；主题总课 ≤ 200。课号须从 1 连续。

## 6. 数据模型

### 6.1 `content_modes`

| 字段 | 说明 |
|---|---|
| id | 主键，如 `mode-course-system` |
| code | 唯一，如 `course_system` |
| name / description | 展示 |
| status | `enabled` / `disabled` |
| sort_order | 排序 |
| created_at / updated_at | 时间 |

### 6.2 `content_themes`

| 字段 | 说明 |
|---|---|
| id | 主键，如 `theme-ai-self-study-zero` |
| mode_id | 所属模式 |
| code | 模式内唯一 |
| name / description | 展示 |
| status | `draft` / `ready_for_review` / `enabled` / `disabled` |
| sort_order | 排序 |
| briefing_json | 问卷 |
| curriculum_draft_json | AI/人工课表草案 |
| route_narrative | 确认后的路线说明 |
| defaults_json | 默认生成偏好（篇幅、语气） |
| created_via | `seed` / `wizard` |
| generate_job_id | 最近一次课表生成 job |
| created_at / updated_at | 时间 |

### 6.3 `courses` 增补

- `theme_id` VARCHAR(128) NULL → 回填后建议非空；索引 `ix_courses_theme`

权威路线顺序：`course_series.sort_order` + `courses.lesson_no`。不新建独立 route 表。

种子：插入 `mode-course-system`、`mode-hot-news` 及现有两主题行；`theme-ai-self-study-zero` 的 `created_via=seed`。

## 7. API

### 7.1 只读

- `GET /api/modes` — 模式含主题列表（课程体系主题来自 DB；热点主题可仍兼容）
- `GET /api/modes/{modeId}/themes`
- `GET /api/themes/{themeId}`
- `GET /api/themes/{themeId}/route`
- `GET /api/themes/{themeId}/series`
- `GET /api/themes/{themeId}/courses` — 已有成文坊聚合

### 7.2 向导与写

- `POST /api/modes/{modeId}/themes/drafts` — 创建草稿
- `PATCH /api/themes/{themeId}/briefing` — 合并问卷
- `POST /api/themes/{themeId}/curriculum:generate` — 异步生成草案
- `GET /api/themes/{themeId}/curriculum-draft`
- `PUT /api/themes/{themeId}/curriculum-draft` — 人工编辑草案
- `POST /api/themes/{themeId}/curriculum:commit` — 落库系列+课壳，`enabled`
- `PATCH /api/themes/{themeId}` — 元数据/停用
- `DELETE /api/themes/{themeId}` — 按删除规则

Job 类型：`theme_curriculum_generation`。实体类型：`THEME`。

错误码（中文 message）：`THEME_NOT_FOUND`、`THEME_CODE_CONFLICT`、`THEME_INVALID_STATUS`、`THEME_DELETE_FORBIDDEN`、`CURRICULUM_DRAFT_INVALID`、`CURRICULUM_ALREADY_COMMITTED`。

## 8. 前端

- 模式总览：「新建主题」→ `/modes/course-system/themes/new`
- 向导多步 + 确认页（可编辑系列/课）
- 主题卡片：编辑设定 / 停用 / 删除
- 深链使用动态 `theme.code`（`_` → `-`），禁止写死 `ai-self-study-zero`

---

## 9. 验收用例

1. 新建主题走完问卷 → 生成 → 编辑 → 确认，系列数/课次数与确认页一致，路线顺序正确。
2. 新主题与种子主题课表互不串数据。
3. 草稿刷新可恢复；commit 后不可重复 commit（除非显式重建，本期不做重建）。
4. 停用后默认列表不可见；空主题可删；有正文或 seed 主题删除被拒。
5. 种子主题迁移后旧课、版本、任务不丢。
6. 单课生成上下文仅读取本主题邻居与路线。
