# Python 后端重构实施计划

## 1. 目标

在不改变现有 React 页面结构和视觉样式的前提下，将当前 Vite 插件后端迁移为 Python FastAPI 服务，并逐步引入 SQLAlchemy、LangChain、LangGraph、后台任务和 SSE。

本文只定义实施顺序和验收门槛，不代表已经开始编码。

## 2. 已确定决策

- 前端保留 React、Vite、TypeScript 和现有 CSS。
- 后端使用 Python 3.12 和 FastAPI。
- 依赖使用 uv 管理。
- 数据库继续使用 SQLite，开启 WAL。
- ORM 使用 SQLAlchemy 2。
- 数据库迁移使用 Alembic。
- 文本 AI 使用 LangChain 模型层。
- 多步骤生成、审核、修复使用 LangGraph。
- 图片生成使用 OpenAI Python SDK Image API，固定 `gpt-image-2`。
- 后台任务使用 SQLite 任务表和单 worker。
- 前端任务进度使用 SSE。
- 人工审核首轮不使用 LangGraph interrupt。
- API Key 首版继续在本地 SQLite 明文保存。
- LangSmith 预留支持，默认关闭。
- 开发环境一条命令启动前端、API 和 worker。
- 本地生产环境由 FastAPI 托管前端 `dist`。

## 5. 回滚策略

每个阶段独立合并，保留旧接口到新接口通过验收后再删除。

- 数据库迁移前创建备份。
- Alembic 迁移提供 downgrade，复杂内容迁移提供恢复脚本。
- 前端 API 切换使用集中客户端，便于临时切回旧接口。
- AI 修复上线初期提供只读预演模式，不写入文章。
