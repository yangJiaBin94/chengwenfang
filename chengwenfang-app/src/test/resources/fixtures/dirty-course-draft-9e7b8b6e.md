## 开场与本课目标

上一课《准备 MNIST 手写数字数据》把图片分批装进 DataLoader（PyTorch 中负责分批取数据的工具），也搭好了网络结构。此时网络权重是随机生成的，还没训练，预测基本靠猜。本课目标：取一批图片，完成前向计算，读懂输出形状、类别分数和预测结果，为下一课损失函数做准备。

## 核心概念

前向计算指图片从输入层经过各层到输出层。输入一批图片，形状为 `(batch_size, 1, 28, 28)`：`batch_size` 是每批图片数，`1` 是灰度通道，`28 × 28` 是像素行列。输出形状为 `(batch_size, 10)`，每行对应一张图片，10 列对应 0 到 9 的**类别分数**。类别分数是网络对每个数字类别的原始打分，不是概率，可正可负，也不要求和为 1。分数越大，表示网络越倾向该类别。预测结果用 `torch.argmax(outputs, dim=1)` 取每行最大分数的位置。

## 具体例子

取一批两张图：

```python
import torch
images, labels = next(iter(test_loader))
outputs = model(images)
predicted = torch.argmax(outputs, dim=1)
print(images.shape, labels, outputs, predicted)
```

在 Windows 和 macOS 下，这段代码都在上一课的项目环境中运行，命令相同。预期 `images.shape` 为 `torch.Size([2, 1, 28, 28])`，`labels` 为类似 `tensor([3, 5])` 的真实标签，`outputs` 形状为 `2 × 10`，`predicted` 为类似 `tensor([3, 8])` 的预测。

假设 `outputs` 两行分数为：

第一张：`-0.12, 0.05, -0.31, 0.62, -0.08, 0.11, -0.22, 0.03, -0.17, 0.09`

第二张：`0.21, -0.44, 0.07, -0.05, 0.33, 0.02, -0.26, 0.18, 0.41, -0.11`

第一行最大 `0.62` 在位置 3，预测 3。第二行最大 `0.41` 在位置 8，预测 8。真实标签若是 `[3, 5]`，第二张猜错，正常。把 `batch_size` 改为 64，输出形状为 `64 × 10`，`argmax` 得到 64 个预测。

失败处理：`dim=0` 会在图片间比较，应改为 `dim=1`。若 `images.shape` 不是 4 维，检查 DataLoader 的批次处理。
