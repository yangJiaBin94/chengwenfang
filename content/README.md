# Learning content (optional)

This repository does **not** ship personal course drafts, WeChat articles, or
generated images.

- Bootstrap seed imports a **demo** course / hot-news theme shell from
  `scripts/bootstrap/default-themes.json` (no lesson body text).
- To import your own markdown tree later, place it under
  `content/learning-content/` locally and call
  `POST /api/migrations/sync-learning-content` (see product README).
- Do not commit private manuscripts, screenshots of secrets, or large media
  into the public tree.
